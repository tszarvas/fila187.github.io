# SEO

- Canonical, hreflang (`hu`, `en`, `x-default` -> `/`), `og:locale` / `og:locale:alternate`, OG/Twitter tags and JSON-LD `Person` stay in sync across locales.
- URLs are absolute (`https://tamasszarvas.me`) with a trailing slash.
- When the OG image changes, bump the `og-image-vN` suffix: rename the file in `public/` and update every reference.
- The sitemap is generated by `@astrojs/sitemap`; do not add a hand-written `sitemap.xml`. `/404` is excluded from it and is `noindex`.
- `public/robots.txt` points to `https://tamasszarvas.me/sitemap-index.xml`.
