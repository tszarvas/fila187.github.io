# i18n

- Every copy change updates both `hu` and `en`.
- Hungarian is the default (served at `/`) and the fallback; English lives at `/en/`. `useTranslations` falls back to HU for a missing key.
- No copy hard-coded in components. UI strings live in `src/i18n/ui.ts`, content in `src/data/*.ts` as `{ hu, en }` fields.
- Values that do not change per language (badges, dates, company names, tags) are stored once.
- `type Lang = 'hu' | 'en'` is exported from one place; import it, do not redeclare it.
- No client-side language detection or redirect. The language toggle is a plain link built with `getAlternateUrl`.
